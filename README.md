# Custom-Modified-ESP32-S3
This ESP model has ESP32-S3-WROOM-1 as its main microcontroller block. In addition it has built-in sensors like 9-Axis Gyroscope , Barometer/Altimeter and most importantly four power pins that can power loads up-to 2A.

### • Sensors
The PCB has two sensors :
1) IMU(MPU-9250) 9-Axis Gyroscope/Accelerometer
2) BMP-280 Absolute Barometric Pressure Sensor/Altimeter
